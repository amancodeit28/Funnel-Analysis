## Marketing Funnel Analysis
• Building an end-to-end marketing funnel analysis to track and understand user behavior across different stages of
the funnel — awareness, interest, consideration, and conversion.
• Using Python, Pandas, and NumPy for data cleaning, transformation, and funnel stage aggregation.
• Visualizing funnel drop-off rates and user journey patterns using Matplotlib, Seaborn, and Plotly for interactive
and statistical insights and Planning to extend the project with advanced analytics.
